# Profile Images

This directory contains profile and personal images for the portfolio:

## Required Images:
- `profile-main.jpg` - Main profile photo (recommended: 400x400px)
- `profile-about.jpg` - About section photo (recommended: 300x300px)  
- `profile-hero.jpg` - Hero section background or photo (recommended: 1200x800px)

## Image Guidelines:
- Use high-quality images (minimum 300 DPI)
- Optimize for web (compress to reasonable file sizes)
- Consider providing multiple sizes for responsive design
- Supported formats: JPG, PNG, WebP

## Placeholder Images:
For development, you can use placeholder services like:
- https://picsum.photos/400/400 (for profile photos)
- https://via.placeholder.com/400x400 (for generic placeholders)

## Implementation:
Import images in components using:
```javascript
import profileImage from '../assets/images/profile/profile-main.jpg';
```
